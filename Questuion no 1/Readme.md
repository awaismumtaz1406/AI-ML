## Project Overview

This project implements a simple Library Management System using Object-Oriented Programming (OOP) concepts in Python.

The system allows users to add, search, and remove books and magazines from a library collection. It also handles invalid item searches using a custom exception.

## Technologies Used

- Python 3
- Object-Oriented Programming (OOP)

## OOP Concepts Implemented

### 1. Classes and Objects
Created classes to represent library items and the library itself.

### 2. Inheritance
Created `Book` and `Magazine` classes that inherit from the base `Item` class.

### 3. Encapsulation
Organized item-related data and behavior within classes.

### 4. Polymorphism
Different item types can provide their own behavior while sharing a common parent class.

### 5. Exception Handling
Implemented a custom `ItemNotFoundError` exception to handle searches for items that do not exist.

## Main Classes

| Class | Responsibility |
|---|---|
| `Item` | Base class for library items |
| `Book` | Represents a book |
| `Magazine` | Represents a magazine |
| `Library` | Manages the library collection |
| `ItemNotFoundError` | Handles missing item errors |

## Main Features

- Add books and magazines to the library.
- Search for an item using its ID.
- Remove an item from the library.
- Store library items using a Python dictionary.
- Display appropriate messages when an item is not found.
- Demonstrate inheritance, encapsulation, and exception handling.

## How to Run the Project

### Step 1: Check Python Installation

```bash
python --version
```

### Step 2: Run the Python File

```bash
python library_manager.py
```
